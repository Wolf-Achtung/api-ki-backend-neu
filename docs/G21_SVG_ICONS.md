# G21: SVG Icon Library

Minimal outline SVG icons for PLATIN++ Design Enhancement System.

All icons are 24x24 viewBox, stroke-only (no fill), stroke-width: 1.5, designed for inline use.

## Usage in LLM-Generated HTML

When generating HTML content for report sections, use these SVG icons inline within the appropriate CSS classes.

## Color Usage

Icons automatically inherit color from their parent via `stroke="currentColor"`.

Use CSS classes to control color:
- `.risk-low` → green (#22c55e)
- `.risk-medium` → amber (#f59e0b)
- `.risk-high` → red (#dc2626)
- Default → brand primary (#3b82f6)
