# G28: Strategy Engine – 12-Month AI Strategy

## Purpose

Generates a comprehensive 12-month AI implementation plan with 8 clearly defined building blocks.

## 8 Building Blocks

### 1. Vision Statement
- **Headline**: Concise vision for AI transformation
- **Description**: 1-2 sentences on strategic direction
- **Target State**: Concrete picture of success after 12 months
- **Time Horizon**: Default 12 months

### 2. Priority Matrix (4-Quadrant)
- **Quick Wins**: High Impact, Low Effort → Start immediately
- **Strategic**: High Impact, High Effort → Plan & prioritize
- **Fill-In**: Low Impact, Low Effort → When capacity allows
- **Avoid**: Low Impact, High Effort → Do not prioritize

### 3. 3-Phase Roadmap
- **Phase 1 (Month 1-3)**: Foundation – Setup & Quick Wins
  - Select and set up AI tools
  - Basic team training
  - First automation live
  - Budget: ~30%

- **Phase 2 (Month 4-6)**: Expansion – Scale & Integrate
  - Automate workflows
  - Track KPIs
  - Apply for/secure funding
  - Budget: ~40%

- **Phase 3 (Month 7-12)**: Optimization – Optimize & Innovate
  - Full integration
  - Achieve ROI targets
  - Plan next phase
  - Budget: ~30%

### 4. Tool Deployment Plan
Based on G25 Tools Engine 4.0:
- Tool name
- Phase assignment (1, 2, 3)
- Priority (Must Have, Should Have, Nice to Have)
- User scope (all, team leads, specific roles)
- Training hours
- Monthly cost

### 5. Funding Integration Plan
Based on G26 Funding Matrix:
- Funding programme name
- Year (2025, 2026, 2027)
- Application phase (1, 2, 3)
- Target amount
- Requirements met
- Open requirements
- Deadline

### 6. KPI Targets
Based on G23 KPI Engine:
- KPI name
- Current value
- Target at 3 months
- Target at 6 months
- Target at 12 months
- Unit
- Category (efficiency, quality, cost, adoption)

### 7. Risk Mitigation Plan
- Risk name
- Probability (low, medium, high)
- Impact (low, medium, high)
- Mitigation strategy
- Owner
- Contingency plan

### 8. RACI-Light Responsibility Matrix
- **R** = Responsible (Does the work)
- **A** = Accountable (Owns the outcome)
- **C** = Consulted (Provides input)
- **I** = Informed (Kept updated)

## Size Adaptation

### Solo Entrepreneurs
- Simplified RACI (Owner = R+A for everything)
- Focus on self-service tools
- Shorter training times
- Smaller budgets

### Team (2-20 employees)
- Clear role distribution
- Team leads as multipliers
- Moderate training effort
- Medium budgets

### SME (20+ employees)
- Full RACI matrix
- Include compliance officer
- Comprehensive training programs
- Larger budgets, more funding options

## Integration

- **G23**: KPI data for target values
- **G25**: Tool recommendations for deployment plan
- **G26**: Funding programmes for financing plan
- **G20/G24**: Industry context for priorities

## Output

`STRATEGY_PLAN_HTML` – Complete HTML block for PDF page with all 8 building blocks.
